# Visual System

## Status

Foundation locked; exact fonts/accent color remain to be finalized after content and asset review.

## Color

### Foundation
- Near Black: `#080808`
- Warm Off White: `#F1EFE8`
- Muted Gray: `#8A8A8A`

### Accent
One accent color only. **TBD** after imagery/content review.

Do not introduce rainbow gradients as decoration.

## Typography

Use a two-font strategy:

### Display
Expressive, oversized, editorial, potentially condensed/variable.

### UI / Body
Neutral grotesk, highly legible, restrained.

Exact font families are TBD.

## Typography Principles

- Oversized type is a compositional object.
- Cropping is allowed.
- Text can extend beyond the viewport.
- Avoid excessive font styles.
- Body copy stays readable.
- Small metadata should be precise and quiet.

## Layout

Prefer:
- Asymmetry
- Large negative space
- Strong alignment anchors
- Editorial grids
- Variable image dimensions
- Intentional overlap

Avoid:
- Equal-width card grids everywhere
- Excessive rounded cards
- Centering everything
- Decorative UI without purpose

## Borders

Use borders sparingly and thinly.

## Image Treatment

Possible:
- Mask reveal
- Scale
- Parallax
- Subtle distortion
- Grain
- Monochrome → color
- Cinematic crop

## Texture

Use subtle film grain/noise only where it improves atmosphere. Never allow texture to reduce legibility.

## Visual Hierarchy

1. Major typography
2. Primary visual
3. Project/title information
4. Supporting metadata
5. Navigation/UI details

## Design Rule

> Strong composition should carry the design before effects are added.
