# Responsive Specification

## Philosophy

Mobile is an intentionally designed version of the experience, not a collapsed desktop layout.

## Breakpoints

Use a small number of meaningful responsive ranges rather than excessive breakpoints.

Exact values should follow the chosen CSS system.

## Desktop

May use:
- Full-screen cursor
- Pinned project scenes
- Horizontal archive
- Large typography
- Complex spatial composition
- Advanced parallax
- Optional 3D

## Tablet

- Reduce animation distance
- Reduce typography scale
- Simplify pinned scenes
- Preserve hierarchy

## Mobile

- No custom cursor
- Vertical archive fallback
- Reduced parallax
- Reduced pinning
- Shorter scroll distances
- More conservative image sizes
- Clear touch targets
- Reduced motion complexity

## Navigation

Mobile navigation should remain full-screen if it benefits the design, but must be easy to close and keyboard accessible where applicable.

## Typography

Do not allow oversized desktop type to cause:
- horizontal overflow
- clipped critical content
- unreadable line lengths

## Performance

Mobile should receive the strongest performance safeguards.
