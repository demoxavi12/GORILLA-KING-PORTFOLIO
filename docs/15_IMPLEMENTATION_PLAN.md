# Implementation Plan

## Phase 0 — Reconnaissance

- Inspect current portfolio/codebase if available
- Inspect inspiration assets
- Inspect approved resume/content
- Confirm project list
- Confirm assets
- Confirm fonts

### Done when
The implementation team understands the source material and does not need to invent content.

## Phase 1 — Foundation

- Create Next.js project
- TypeScript
- Tailwind
- Global styles
- Font loading
- Metadata foundation
- Basic route structure

### Done when
The application runs cleanly and base styles are stable.

## Phase 2 — Motion Infrastructure

- Lenis
- GSAP setup
- Motion utilities
- Reduced-motion handling
- Shared timing/easing

### Done when
Scroll and animation primitives work without scattered implementations.

## Phase 3 — Global Interface

- Navigation
- Full-screen menu
- Cursor
- Page shell
- Global transition layer

### Done when
The interface feels coherent before sections are filled.

## Phase 4 — Entry + Hero
