# Design Blueprint

## 1. Creative Direction

An experimental digital portfolio for **Sabya Sachin Mohanta** where development, design, motion, and visual storytelling meet.

### Keywords
Cinematic · Editorial · Experimental · Minimal · Technical · Immersive · Precise · Dark · High contrast · Motion-driven

### Must Not Feel Like
- Generic developer portfolio
- SaaS landing page
- Template
- Generic AI/vibe-coded UI
- Excessive glassmorphism
- Random gradient decoration
- Animation for animation's sake
- Standard project-card grid

## 2. Core Principle

> The website itself is the project.

The experience should feel continuous rather than like a stack of unrelated sections.

## 3. Experience Map

`Loader → Hero → Manifesto → Selected Work → Project Experiences → Visual Archive → Experience/Skills → About → Contact → Footer`

## 4. Loader / Entry

The current portfolio's entry animation is a reference point and should be evolved, not casually discarded.

Conceptual sequence:

`BLACK → MICRO TYPOGRAPHY → NAME REVEAL → IMAGE/ENVIRONMENT → HERO`

Requirements:
- Cinematic reveal
- Masking/clipping rather than only opacity
- Approximately 1.5–2.5 seconds on normal loads
- Must not unnecessarily block interaction

## 5. Hero

Oversized editorial typography, strong composition, restrained environmental imagery, and scroll-driven transformation.

The hero should transform as the visitor scrolls rather than simply move upward.

## 6. Manifesto

Use one large statement plus concise support text.

Potential interaction:
`Vertical scroll → horizontal typography movement`

Final copy must come from Sabya's actual content.

## 7. Selected Work

Do not use a conventional card grid.

Projects should use:
- Large project titles
- Editorial metadata
- Large visual areas
- Pinned viewport choreography
- Scroll-controlled transformations
- Project takeover transitions

## 8. Project Detail

A project should visually expand from its current position when possible.

Case-study structure:
- Title
- Year
- Role
- Team
- Stack
- Overview
- Problem
- Approach
- System/process
- Result
- Technology
- Next project

## 9. Visual Archive

A cinematic visual section inspired by the photography references.

Purpose: demonstrate taste and personality beyond technical work.

Possible behavior:
- Horizontal exploration
- Variable image speeds
- Parallax
- Scale changes
- Metadata
- Drag interaction where appropriate

## 10. Experience / Skills

Avoid a giant skill list. Present technologies spatially and editorially, then reveal detail through interaction.

## 11. About

A deliberate slowdown:
- Portrait/visual
- Short actual biography
- Relevant personal information
- Minimal motion

## 12. Contact

The final major scene should become quieter and more typographic.

Use actual contact information only.

## 13. Menu

Minimal closed state; full-screen composed state when opened.

Navigation:
- Home
- About
- Work
- Archive
- Contact

Exact labels can change after content review.

## 14. Cursor

Contextual states:
- Default
- Link
- Project
- Image
- Drag
- Menu
- External link

Disable/simplify on touch devices.

## 15. BLEACH-Inspired Motion Language

Use only abstract principles:
- Impact
- Speed
- Pressure
- Void
- Black/white contrast
- Directional/slash-like transitions
- Sudden acceleration
- Stillness → impact
- Transformation

Do not use copyrighted characters, artwork, logos, or copied scenes.

## 16. Core Rule

> Do not maximize the number of animations. Maximize the quality of the experience.
