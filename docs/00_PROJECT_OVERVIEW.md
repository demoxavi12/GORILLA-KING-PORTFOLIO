### Aspirations Reference Folder

Claude MUST inspect the entire `/aspirations/` folder before making major visual or interaction decisions.

Use the references to extract:

- Layout principles
- Typography ideas

- Interaction ideas
- Image treatment

- Cinematic visual language
- Composition ideas
- Motion references

### Important

Do **not** directly reproduce any reference website, screenshot, layout, animation sequence, or branded visual identity.

Instead:

1. Study the reference.
2. Identify the underlying design principle.
3. Adapt the principle to the portfolio's own content and identity.
4. Combine ideas from multiple references.
5. Produce an original result.

The final website should feel **inspired, not derivative**.

## Non-Negotiables

- No generic template appearance.
- No arbitrary animation overload.
- No invented personal facts.
- No copying reference websites.
- No unnecessary dependency proliferation.
- No giant monolithic page component.
- No performance sacrificed for visual effects.
- Mobile must be intentionally designed.
- Accessibility and reduced-motion support are required.
- Git pushes remain manual and only happen when explicitly requested.

## Definition of Success

A visitor should remember the experience, understand Sabya's work quickly, and leave with the impression that the portfolio was deliberately art-directed rather than generated from a template.
